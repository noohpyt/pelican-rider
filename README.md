# Pelican Rider

一只神情严肃的鹈鹕、一辆珊瑚橙自行车，以及约 60 秒的海岸骑行。使用 Vite + Three.js；角色、自行车、鱼、路障、棕榈、道路、海洋和天空均由代码生成，不加载 3D 模型、图像贴图或精灵替代 3D 对象。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

打开 `http://127.0.0.1:5173`。

```bash
npm test       # 纯逻辑与 Three.js 动画集成测试
npm run build  # 输出 dist/
npm run preview
```

## 操作与规则

- `W` / `↑`：加速；不按加速键时缓慢巡航。
- `S` / `↓`：刹车直至停止；停车时车轮和曲柄停止。
- `A D` / `← →`：转向，前轮、整车朝向与车身倾斜联动。
- `Shift` / `空格`：按住冲刺。
- 鲜鱼：`+100` 分、`+0.5` 秒，倒计时最多为 60 秒。
- 路障：扣 1 点生命和 50 分，并短暂减速；1.8 秒无敌期避免连续扣血。
- 三点生命耗尽即失败；倒计时结束即完成。结算后点击按钮或按 `Enter` 重开。
- 触屏设备提供左转、加速、冲刺、右转按钮；刹车仍可使用外接键盘。

## 实现结构

- `src/game-core.js`：固定小步长状态更新、计时、速度、生命、碰撞和计分。
- `src/models.js`：程序化网格、整车关节和逐帧动画。
- `src/animation.js`：踏板轨道、两骨腿部 IK、曲柄传动与转向角。
- `src/world.js`：循环道路、几何海岸装饰、动态海面和渐变天空。
- `src/main.js`：生成物、碰撞、镜头、粒子、输入和 HUD。
- `src/effects.js`：共享粒子材质，避免反复创建 GPU 资源。

踩踏板由车速和传动比驱动；左右脚反相，膝盖由两骨 IK 求解。测试会检查整圈踏板与曲柄臂端点距离、车轮和曲柄旋向，以及整车转向方向。
