# 鹈鹕骑自行车

一只鹈鹕骑着自行车在海上公路前进。高位追尾视角，两侧是不断涨潮的大海。自动加速，左右变道躲避石头、收集水桶。带合成音效与 BGM。

## 在线试玩

https://noohpyt.github.io/pelican-rider/

## 操作

| 按键 | 作用 |
| --- | --- |
| `A` / `←` | 向左变道 |
| `D` / `→` | 向右变道 |
| `Enter` | 开始 / 重新开始 |
| `Esc` | 关闭帮助 |

触屏设备提供左右两个按钮。

## 规则

- 自行车自动持续加速，存活越久速度越快、难度越高。
- 路上有大石头，撞上会扣 1 点生命、速度回落并损失燃料。
- 收集水桶（里面有活蹦乱跳的小鱼）可以补充燃料、获得分数。
- 只剩 1 点生命时，水桶有 10% 概率刷新为红心，拾取后恢复 1 点生命。
- 燃料耗尽或 3 点生命耗尽则游戏结束，结算界面显示存活时间和超越玩家比例。
- 到达目标距离即可过关。
- 顶栏 ♪ 按钮可开关声音。
